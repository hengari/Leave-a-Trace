> 分析对象：https://project-workbench-v014.pages.dev/（标题「项目工作台 · 基础版」，Next.js + Cloudflare Pages）
> 复刻落点：留痕 `src/web/` 新增「项目工作台」模块（`#workbench`）
> 分析日期：2026-08-06

## 0. 重要事实说明

- 用户提供的链接 `https://project-workbench-v014.pages.dev/xian` 实际返回 **404**；该站点是单页应用（Next.js client component），只有根路径 `/` 可访问，`xian` 不是本版本的有效路由。以下分析基于根路径实际渲染结果。
- 站点是**纯浏览器本地版**：除静态资源外无任何后端请求，全部数据保存在 `localStorage` 单键 `project_workbench_v01_state`，即开即用、不自动同步。
- 源码已从 `/_next/static/chunks/app/page-*.js` 提取，本复刻按可观测行为 + 源码逻辑双重还原。

要点：
- 任务四态为「待开始 / 进行中 / 已完成 / 已逾期」，其中**已逾期是派生状态**：`dueText` 内出现 `YYYY-MM-DD` 且早于今天，或状态字段本身为已逾期。
- 任务默认归属「个人待办」；「待归类」不是项目名，只是分类状态。
- 附件在浏览器版里以 dataURL 存入 localStorage 并标记「已记录」；若项目绑定了本地资料文件夹（File System Access API），状态标记为「已归档到本地资料文件夹」，权限失效则「未归档，请重新授权文件夹」。

## 3. 核心规则（源码级还原）

### 3.1 任务卡片纯文本解析（任务录入）

输入先按 `【任务\d+】` 分段，命中「任务名称：」即按卡片解析，每段用正则 `字段：([^\n]*)` 提取 8 个字段：

`任务名称 / 所属项目 / 归类状态 / 负责人 / 截止时间 / 优先级 / 来源 / 备注`

没有卡片格式时降级为**逐行手写解析**：每行作为一条任务，默认项目「个人待办」，截止时间按关键词猜测（今天/明日→今天、明天→明天（日期）、周五/星期五→本周五、下午→今天下午，否则未明确），来源写「手动录入」。

### 3.2 状态机与分组

- 有效状态 `J(task)`：已完成 → 已完成；已逾期 → 已逾期；dueText 含早于今天的日期 → 已逾期；否则取状态字段。
- 工作台今日待办分组：已逾期 / 今天（非逾期且 dueText 不含“明天/本周/周五/近”）/ 快到期（含“明天/本周/周五/近”）。
- 项目统计：未完成、已逾期、今日进展（进展记录或完成时间落在今天）、待归类、完成率（已完成 ÷ 总数）。
- 完成任务：状态置已完成，写 `completedAt/statusUpdatedAt`；改回进行中/待开始时清除 `completedAt`。

### 3.3 日报 / 周报生成

按时间范围（今天/昨天/本周/上周/自定义，周从周一起算）+ 项目筛选聚合：

1. 圈定在范围内有动作的任务（完成时间 / 进展时间 / 附件时间 / 创建时间任一命中）；
2. 按项目分组输出：`N. 项目名` + 每条 `- 完成xxx` / `- 推进xxx：内容` / `- 补充xxx相关资料：文件名`，无动作且当日新建则 `- 新增待办：xxx`，每组最多 6 条；
3. 附「待跟进事项」（未完成且未逾期，最多 6 条）与「风险 / 已逾期」清单；
4. 空范围输出「当前范围内暂无可汇总的工作内容。」，复制/保存均可用。

### 3.4 任务清单筛选

- 快速筛选：全部 / 今天（dueText 含“今天/今日”或等于今天日期）/ 近 7 天（原站实现为仅排除已完成）/ 已逾期 / 未分项目（待归类）/ 待开始 / 已完成；
- 叠加维度：项目、状态、标题关键词搜索；
- 批量操作：勾选后「完成所选」「移动到项目（自动置已归类）」「删除所选（二次确认）」。

### 3.5 AI 助手与 V5 初始指令

- 内置 5 个常用 AI：DeepSeek / ChatGPT / Kimi / 豆包 / 通义千问；
- 「打开 AI」在屏幕右侧开一个固定尺寸弹窗并跳转到所选 AI 站点；「复制初始指令」把 V5 长指令（替换当前日期）复制到剪贴板，再粘贴给 AI，让 AI 把微信截图/聊天记录/领导指令拆成任务卡片；
- 指令约 5000 字，包含：核心原则、内容类型判断（项目列表/背景/任务清单/任务详情/普通消息/进展）、项目归类规则、负责人判断规则、新任务卡片输出格式、任务进展输出格式、无需处理格式、输出总要求。全文已内嵌进复刻版，可在 AI 助手面板「查看初始指令」处查看。

### 3.6 新手引导（onboarding）

三步清单：选择常用 AI → 发送工作台初始指令（复制并打开 AI）→ 录入第一条任务（导入后自动完成引导）。可在设置里「重新查看新手引导」。

## 5. 已知差异（浏览器本地版的边界）

- **附件写入磁盘**：原站在 Chrome/Edge 下可用「选择本地资料文件夹」把附件写入磁盘；浏览器版文件系统 API 仅在 Chromium 内核可用，复刻版保留入口与状态标记，写入失败/不支持时只保留附件记录（dataURL），并在设置中说明。
- **AI 助手**：复刻版不接任何后端，行为与原版一致——复制指令 + 打开 AI 站点，由用户粘贴给 AI 拆解。
- **支持作者**：原站赞赏入口的收款方式未知，复刻版保留按钮与弹层占位文案。
- **近 7 天筛选**：按原站逻辑仅排除已完成任务，未做更严格的日期过滤（保持一致）。
